# Item Tracking System

## Project Overview

The Item Tracking System is a simple Python-based application designed to manage item records.

The system allows users to add, view, search, update, and delete items. Item information is stored in a JSON file so that the data can be retained when the program is closed.

## Features

- Add a new item
- View all items
- Search for an item
- Update item details
- Delete an item
- Store data using JSON
- Validate item IDs and quantities

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling
